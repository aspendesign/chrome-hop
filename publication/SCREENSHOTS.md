# Listing screenshots

These are actual captures from the isolated Firefox 159.0 integration run.
They are unretouched and contain only task-owned fixture/extension pages.

- `screenshots/toolbar-handoff.png`: Chrome Hop pinned in the Firefox toolbar,
  with the success tick after a real native-helper response. The Firefox tab
  remains open. The localhost fixture independently recorded Chrome’s request.
- `verification/setup-1.1.0.png`: current packaged setup instructions with a
  direct **Download for Windows** button and separate **View on GitHub** button.
  Uploaded to the Mozilla listing on October 21, 2026, replacing the older setup
  screenshot. Caption: "Quick setup: Download for Windows starts the installer
  download directly. View on GitHub opens the source, release details and
  checksums separately."

Exactly two saved screenshot captions were verified after reopening Mozilla's
Images editor. `screenshots/setup-help.png` is retained as a historical 1.0.0
capture and is no longer the setup screenshot in the listing.

The icon under `assets/` is original artwork made for Chrome Hop. Do not label
these captures as a Chrome screenshot or imply that the helper was obtained
through Mozilla. It is a separate Windows installation from GitHub Releases.
