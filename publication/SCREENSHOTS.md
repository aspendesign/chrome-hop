# Listing screenshots

These are actual captures from the isolated Firefox 159.0 integration run.
They are unretouched and contain only task-owned fixture/extension pages.

- `screenshots/toolbar-handoff.png`: Chrome Hop pinned in the Firefox toolbar,
  with the success tick after a real native-helper response. The Firefox tab
  remains open. The localhost fixture independently recorded Chrome’s request.
- `screenshots/setup-help.png`: packaged, actionable missing-helper instructions,
  including the official download and troubleshooting links.

The icon under `assets/` is original artwork made for Chrome Hop. Do not label
these captures as a Chrome screenshot or imply that the helper was obtained
through Mozilla. It is a separate Windows installation from GitHub Releases.
