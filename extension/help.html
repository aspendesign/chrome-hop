CHROME HOP

ONE CLICK. YOUR TAB IN CHROME.

One small setup.
Then you’re ready to hop.

Chrome Hop needs its Windows helper to open Google Chrome.

  1. 1
    Install the Windows helper

    Download ChromeHop-Setup from the official release. Run it once. No administrator access needed.

  2. 2
    Return to your Firefox tab

    Open a web page and click the Chrome Hop toolbar button. Your Firefox tab stays right where it is.

Get the Windows helper ↗

Windows 11 · Google Chrome Stable · Firefox 142 or later
