Other ways to install & common questions

Already installed? Run the Windows installer again to repair the connection. Firefox and Chrome can stay open.

Prefer GitHub? Open the release page and choose ChromeHop-Setup-windows-x64.exe. The versioned Setup file is the same installer. The standalone helper and source ZIPs are for developers.

macOS, Linux, or Windows ARM? There is no tested helper for these platforms yet. The Windows installer is for Windows 11 x64.

Why open an installer? Firefox can download the helper, but installing a local program needs your approval. This is a one-time step.

Windows warning? The installer is unsigned. Check the publisher’s source and checksums on GitHub. If your device blocks it, follow your device administrator’s rules.

Requirements: Firefox 142 or later and Google Chrome Stable in its normal Windows installation location.
